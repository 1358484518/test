5. RS485

同一根 485 上有三件事：读电表、接 DLB 主机、产测命令。拨码 bcd3 决定前两件谁接收。调试命令只吃没被 Modbus 解析掉的字节。

5.1 一根线怎么分

项源码事实
引脚PC6 发，PC7 收。方向控制宏 RS485_SET_COMM_SEND/RECV 被注释成空，程序不翻转收发使能
接收main 把 USART2 标成 485。接收回调里 USART2 按拨码分流
发送rs485_send 调用的是 huart6。USART6 接收回调还在，注释写已经不用。收、发不是同一个串口
拨码bcd3_state == 1 进电表主机；为 0 进 DLB 从机
剩余字节中断返回 0 的字节进入 uart_rs485_rx，100 ms 的 tmxsh_process 当调试命令
不要和网口混淆BW20 的 AT+SOCKET=3,502 是 Modbus TCP，不走这根 485

5.2 电表主机

energy_meter_process 每 100 ms。 bcd3_state == 0 时直接返回，不发电表命令。

步骤条件结果
改参数波特率或地址变化meter_uart_baudrate_set 改 huart6。地址默认 1，合法 1～254。波特率默认 9600，超出 1200～115200 则改回 9600
识别尚未识别到表每 500 ms 交替发东鸿（功能码 0x03）和 BG（0x04）的型号命令
东鸿型号字节0x0089 / 0x0020 或 0x0004 / 0x00E1SDM72 / SDM120M / SDM54
BG 型号字节0x0065BG 表
30 秒仍无表超时计数写成 31大于 20 即电表故障，告警，充电中进暂停
已识别约每 500 ms电压电流功率 与 电量 两条命令交替。应答地址必须等于 meter_address，功能码 0x03 或 0x04

5.3 DLB 从机

RS485_slave_process 每 5 ms。代码里的从机地址 rs485_slave_addr 固定 0x01。调试命令改的 dlb_id 没有赋给这个变量。

条件动作
dlb_mode == 0 或拨码在电表侧清通信故障，允许电流等于额定电流，函数返回
模式 1 且 60 秒没有合法帧通信故障置位，电流收到 6A。故障码 13，紫灯，不停充
地址不是 0x00、0xFF、0x01丢弃
功能码 0x10，寄存器 0，3 个寄存器 6 字节，CRC 正确三相取三相电流最小值。单相按相序 0～3 / 4～5 / 6～7 取第 1 / 2 / 3 相。只把 dlb_current 改小
功能码 0x06，寄存器 1，CRC 正确电流等于数据字节，同样只改小
每 5 秒，且模式 1、正在充电小于目标则加 1A，大于目标则立刻收到目标。等待和准备里模式 1 会把电流复位成 6A

这个电流是 CP 占空比的最后一道上限，小于 6A 时不再发方波。

只有没被电表或 DLB 状态机吃掉的字节，才会在 100 ms 任务里被当成字符串。

命令做什么

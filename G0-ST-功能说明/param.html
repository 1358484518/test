参数存储

运行参数是 system_param_t sys_param，1 字节对齐。掉电保存写在 MCU 内部 Flash，不写外部 W25Q。外部 Flash 只放固件、授权名单和离线记录。

2. 上电选哪一块

main 调用 ParamBlock_init，然后 SysConfig_Init 里 sys_param_get 从选中的块把数据拷进 RAM。param_read 不再验 CRC。

顺序条件动作
1主区 3 块里有魔数正确且 CRC 一致的块取序列号最大的一块，作为 latest_block
2主区没有合格块用同样规则扫备份区 sector 121。找到则擦主区，把该块抄回主区。日志：use 2
3主区和备份区魔数都整区无效（各至少 3 块魔数错）扫第三份 sector 119。找到则擦主区和备份区，两份都写回。日志：use 0
4第三份魔数在，但 CRC 都不对仍用序列号最大的那块，重算 CRC 后写回主区和备份区。日志：0 crc error, use 0
5三份都没有可用魔数擦主区和备份区，写一块数据区全 0xFF 的空块，序列号 0。日志：erase_param_sector 0
6主区魔数全无效，备份区还有魔数但 CRC 错用备份区序列号最大的块重算 CRC，写回主区并擦备份区再写。日志：use 1 或 use 2
读出之后条件动作
版本或芯片不对(version & 0xFFFFFF00) != 0x5AA58000，或 uniqueID 不等于本芯片 UID 的 8 位十六进制整份恢复默认并写入，安全参数也重置。SYS_PARAM_VERSION 当前是 0x5AA58003
旧版本升级版本小于 0x5AA58001离线充电时间补成 10 分钟
旧版本升级版本小于 0x5AA58002过压、欠压门限补成默认值
收尾每次 SysConfig_Initcheck_config_info 把明显非法的字段改成默认，然后无条件再 sys_param_set 一次

4A. 每个参数实际控制什么

上一节是能不能写入。这一节是写进去之后程序用它做什么。没有读到使用点的字段单独列在最后，移植时不要假设它们已经生效。

参数控制的功能程序行为
chargemode谁能开始充电1：刷卡可走 OCPP Authorize，远程启停只在这个模式改授权。2：只认本地卡。3：刷卡函数为空；100 ms 任务插枪满 1 秒后用 freeIdTag 自动授权。默认 3
rated_currentCP 电流上限PWM 合成的起点，也是家庭负载关闭时的 dlm_current。过流门槛默认用它，枪线时再和 PP 取小
max_temperature过温和降功率达到该值持续 5 秒报过温，充电进暂停。低 5℃ 持续 5 秒把 PWM 限到额定一半。回到低 12℃ 以下才恢复
power_distribution_enable家庭负载0：dlm_current 等于额定电流。1：可用电流 = home_power_current − 2 − 其他负载，带滞回后写入 dlm_current
home_power_current家庭总电流只在家庭负载打开时使用。读出大于 120 会改回 100
sampling_methord外部电流从哪来0～7。等于 4 时 CT 广播任务去收 UDP；否则若广播间隔大于 0 就向外发 CT。主循环里这个广播函数当前被注释，所以这条只在函数被重新挂上时生效。蓝牙里它叫采样方式
power_meter_type / power_meter_addr家庭电表地址小于等于 0 时改回 1。和充电电表的 meter_address 不是同一个字段
solar_mode光伏限流和自动开充0：光伏电流等于额定，不限制。非 0：按富余功率折电流，并可在等待或结束时用免费身份自动启动
solar_current_from_grid允许从电网取的电流参与光伏提供电流。小于等于 0 时和富余电流相加；大于 0 且富余为负时只用这一段
solar_stable_time光伏滞回默认 10 秒，注释范围 10～3600。升降电流不会每 100 ms 改一次

ocpp_admin_mode / ocpp_admin_url第二路 OCPPmode 为 1 时主循环再握手第二路。第二路不发启停交易和 MeterValues

5. 内部 Flash 和外部 Flash 分开记

两套介质不要混。内部 Flash 由 param_write、ChargingProfile_write 写。外部是 W25Q，函数是 DEV_W25X_Read/Write。安全密钥不单独占内部地址，加密后塞进 sys_param.sec_section，跟参数走同一套三块轮写。

内部 Flash：现在真正在写的

EDATA 在 Bank2，扇区从 0x0900C000 起，每扇区 0x1800（6144）字节。第三份按 Bank1 公式 0x08100000 + 0x2000×扇区号。

地址长度存什么谁写
0x08010000应用偏移链接脚本里的 App 起始。向量表运行时设在 0x08020000。这是程序，不是参数Boot 升级时搬运
0x081EE000sector 119，按 8KB 公式参数第三份。3 块 × 2048，魔数 0xAA552772noedata_BackupParamBlock_write，每次 param_write 最先写这里
0x0900C000sector 120，6144 字节参数主区。同样 3 块 × 2048。上电优先读这里ParamBlock_write
0x0900D800sector 121参数备份区。主区 CRC 全坏时用它回写主区BackupParamBlock_write
0x09012000sector 124，0x0900C000+0x1800×4OCPP 充电计划。整扇区擦除再写，没有三块轮换ChargingProfile_write

起始结束长度存什么
0x000000000x000010004KB升级完成标志。魔数 0x1234ABCD、长度、CRC、名字 App.bin。上电若 fw_update_state 为 1 或 11，读这里决定报成功还是失败
0x000010000x00081000512KB主控固件下载区。OCPP 和网页升级按 1024 字节往这里写
0x000810000x0009100064KB授权缓存。+1 是魔数，+0x80 是条数，再往后是索引和记录，记录区到 0x00085001+0x4000 这一段由 ocpp_offline.c 划分
0x000910000x000D1000256KBOCPP 本地授权名单。布局和缓存相同，索引区更大，记录区约 128KB
0x000D1000下一页4KBis_charging 掉电标志。读出来若为 1，停止原因记成掉电
0x000D20004KB交易电量 transaction_energy_store
0x000D30004KB光伏电量
0x000D8000校准参数 DEV_ROM_SPI_ADDR_CAL_PARAMS
0x000E0000按 4KB 扇区record_flash_read/write 的 NG 区，地址再加调用者给的偏移
0x003E00000x00400000128KB离线 OCPP 交易。第 0 页魔数，第 1 页（+0x1000）交易号，从第 2 页起是补传记录

0x000E0000 到 0x003E0000 之间，循环充电记录和历史记录那套地址宏包在 ChargeRecord_Handle.c 的 #if 0 里，当前工程没有定义，不参与编译。短名单 sys_param.idtag[10] 在内部参数块里，不在外部 Flash。

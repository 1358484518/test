2.1 电流怎么合成

set_current_proc 每 1 ms 执行。起点是 sys_param.rated_current。若 pwm_enable 为 0，电流直接变成 0，后面的上限全部跳过。等待、结束和停机出口都会把这个允许位关掉，所以那些状态下 CP 不会发方波。

允许输出时，按下面顺序往下裁，后一步看不到被前一步丢掉的更大值：

  1. 充电计划有效（sc_profile_valid）：开了光伏就取计划电流和光伏电流的较大值，否则只用计划电流。计划无效但开了光伏，就用光伏电流。两项都关着就保持额定电流。
  2. 不超过 dlm_current（家庭动态负载，见负载）。
  3. 再不超过额定电流。
  4. 打开枪线识别时，不超过 PP 档位，档位只有 13A、20A、32A、63A。
  5. 允许降功率，且内部温度已经达到“保护温度减 5℃”并持续 5 秒：不超过额定电流的一半。温度回到“保护温度减 12℃”以下才取消降功率。温度读数 4095 视为无效，不降功率也不报过温。
  6. 小于 6A 先变成 0。这个值记入 demand_current。
  7. 再不超过 dlb_current（桩群均衡）。小于 6A 再变成 0。

结果和上次不同才更新 pwm_current 并打日志。准备态进充电、充电态吸接触器，看的都是这个最终值，不是额定电流。

2.2 占空比

pwm_current 大于 0 时调用 CP_PWM_SetCurrent。函数内部再把电流夹到 6～63A，所以调用方传入 0 不能走这里，否则会被抬成 6A。

  • 6～51A：占空比百分数 = 电流 / 0.6。
  • 大于 51A 到 63A：占空比百分数 = 电流 / 2.5 + 64。
  • 百分数乘 10，写入 TIM3 通道 3 的比较寄存器。周期寄存器是 999，比较值 0～1000 对应 0%～100%，步进 0.1%。

例子：6A → 10% → 比较值 100；32A → 约 53.3% → 533；63A → 89.2% → 892。这是 IEC 61851-1 的电流通告，程序上限停在 63A，没有做到标准里的 80A。

if (current <= 51)
    pwmduty = (float)current / 0.6f;
else
    pwmduty = (float)current / 2.5f + 64.0f;
CP_PWM_SetDuty(pwmduty * 10);   /* TIM3 周期 999，1000 = 100% */

/* pwm_current == 0 时不走上面，直接： */
CP_PWM_SetDuty(1000);           /* 稳态高电平，不通告电流 */

电流为 0 时调用 CP_PWM_SetDuty(1000)。比较值被限制不超过 1000；等于 1000 时软件记录的 CP 电流清 0。CP 保持高电平，不再发 1 kHz 方波，车辆看到的可用电流是 0。等待、暂停以外的停机、以及电流被限制到 6A 以下，都走这条。

各状态对 PWM 允许位：等待关掉；准备、充电、暂停打开；结束和停机出口关掉。准备进充电额外要求合成电流已经 ≥ 6A，所以占空比还是 100% 稳态时不会吸接触器。

2.3 接触器

交流接触器允许位只在充电态、且 pwm_current ≥ 6 时为 1，同时 PE 接触器允许位置 1。准备、暂停、等待把交流接触器允许位清 0。真正拉 GPIO 的是 set_contactor_proc。

从充电停下来时，充电函数先关 PWM，不立刻断接触器。任一相电流仍 ≥ 1A（采样值 100）时，等待从 200 ms 延长到 6200 ms，避免带电流拉开。单相只看 relay_state，三相任一路反馈为合都算接触器在合。校准模式可以绕过状态机，单独强制继电器。

上电还有一段 PE 接触器是否存在的检测：故障检测允许之后，大约 200 ms 窗口里数 PE 继电器反馈。

2.4 电子锁

锁电机两路方向 PWM：上锁时一侧为 0、另一侧输出占空比；解锁对调。过程中占空比在 100%、72%、95%、50% 之间按 Get_Wait_Time 切换。准备态调用上锁流程，充电态 lock_enable 为 1。结束且锁故障、枪还插着时禁止再上锁，并置 elock_lock_failed。

锁故障发生后的 30 秒内，故障检查返回 2，充电中会进暂停而不是直接结束。超过 30 秒返回 1，按停机处理。掉电有单独的解锁路径。

2.5 灯和蜂鸣器

set_led_proc 的优先级从高到低：

  1. 漏电自检提示：先紫灯常亮约 2 秒；自检成功再绿灯闪约 5 秒。
  2. WiFi 复位标志：黄灯常亮。
  3. 故障码不是 13：红灯按故障码次数闪。13（负载均衡通信）是紫灯闪。故障码对照见保护。
  4. 否则按充电状态：等待且未插枪，绑卡中青灯；模式 1 且还没登录成功是黄灯，已登录是蓝灯；其它模式蓝灯常亮。已插枪的等待、准备、暂停是蓝灯闪。充电是绿灯流水。结束是绿灯慢闪。预约是蓝灯慢闪。不可用是红灯常亮。

刷卡被接受、远程启停会置蜂鸣标志，蜂鸣器由定时器 PWM 驱动。刷卡被拒绝响的是另一档。
